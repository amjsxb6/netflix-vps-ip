## 为什么很多VPS只能看Netflix自制剧

Netflix的版权检测分两层：第一层看你的IP是不是来自IDC机房（数据中心），第二层才看地区归属。普通机房IP很大概率已经被整段封禁——这就是为什么同一台VPS，自制剧能放、版权剧全灰，严重的连自制剧都打不开。
